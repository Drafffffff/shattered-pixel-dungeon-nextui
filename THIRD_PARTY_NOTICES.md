`dependencies.json` pins every distributed Maven binary by URL and SHA256. `third-party/sources-lock.json` does the same for corresponding sources and notices. The Release's `third-party-sources.tar.gz` supplies those archives directly; game/adaptation source is in `source.tar.gz` and this repository. Source archives preserve their own notices, build files and licenses. Libraries are unmodified, separate files in `lib/`; users may replace/rebuild them and modify this adaptation under the applicable licenses. No additional restriction is imposed on debugging modified libraries. LGPL-2.0 text and all collected notices are shipped in the binary package too.

External prerequisites **not redistributed here**: NextUI, system SDL2 and Mali graphics libraries, PortMaster, and the Zulu/OpenJDK 17 runtime. Install these through their respective projects. This package does not include user saves, device logs or third-party cover artwork.
