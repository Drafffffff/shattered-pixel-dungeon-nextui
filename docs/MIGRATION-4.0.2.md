# RG34XX 适配迁移到 Shattered Pixel Dungeon 4.0.2

游戏基线升级到官方 **v4.0.2**，固定提交 `57a4e06a4caf162446d1c28caa7983f0493fecf0`，内部版本号 **922**。完整游戏源码及素材保存在 `vendor/shattered-pixel-dungeon/`，逐文件校验见 `vendor/upstream-manifest.json`。

## 保留的掌机体验

短 B 查看、长 B 搜索，A 互动和邻敌拾取，X 背包，Y 使用/长按管理快捷格，肩键按实际方向切换，Select 状态/长按地图，Select＋Start 保存退出均保留。全屏地图总览、缩放、当前位置高亮、中文小屏布局、弹窗焦点、日志记忆、简洁首页、数字音量提示和快捷格跨楼层记忆沿用。

继续使用原启动入口 **Shattered Pixel Dungeon**、原封面和 `.userdata/shared/shattered-rg34xx/` 存档位置。Java 运行库、SDL/Mali 后端、30 fps 上限与 Java 堆预算不变，无需安装另一套 Java。

## 迁移做法

旧十字键分支基于 3.3.8。它的 Java 控制器改动单独整理为 `ports/shattered-rg34xx/controller-base.patch`，通过三方合并迁移到官方 4.0.2；只包含游戏/引擎 Java 源码改动，不携带旧分支的构建报告和本机路径。后续 RG34XX 补丁在构建副本上应用，官方 vendored 源码保持原样。

针对升级另外修复：

- 有旧角色且教程未完成时，升级先执行原版版本迁移，再进入首页，避免被引向另一场新教程。
- 3.3.8 楼层存档缺少新版可选 `customTerrain` 图层时，按空图层加载，避免产生 JSON 缺字段异常；新版存在的图层完整保留。
- 游戏运行版本和存档写入版本同步为 4.0.2 / 922。
- 中文教程说明同步现有按键，删除已移除放大镜按钮的旧操作提示。

## 旧存档与回退

更新前保存退出，备份 SD 卡的 `.userdata/shared/shattered-rg34xx/`。安装只替换游戏程序，不覆盖存档与设置。旧局使用原版兼容规则：已生成的楼层和已开始的任务可能保留旧内容；完整的新宝库任务体验建议从新冒险开始。

4.0.2 写入的存档不要再交给 3.3.8 打开。回退时同时恢复旧程序和升级前存档备份。SSH 安装保留 `.ports/shattered-rg34xx.previous`，但它不会自动回退存档；手工从 zip 更新时请另外保留旧程序副本。

## 验证范围

ARM64/Mesa 实际渲染验证包括新开局、3.3.8 教程旧档恢复、查看/搜索、背包、投掷取消、地图与 HUD 隔离、Buff/图鉴/日志焦点、快捷格管理、邻敌拾取、文本回滚、炼金选择、下楼与保存重载、死亡菜单等。

新增 `migration-test.py` 使用 3.3.8 存档副本核对职业、等级、层数和金币保持；检查设置/存档升级为 922。它通过正常切层加载器生成 4.0 宝库，验证地图总览与缩放、方向键撞入魔镜/代币门、领取魔镜奖励、代币门取消及开门、逃脱水晶确认/奖励选择/取消与宝库保存重载。测试夹具只在显式 `nextui.commands` 开启时生效，不用于修改真实存档。

软件渲染测试不能替代掌机 Mali GPU、实体按键与长时间游玩的验收。README 中 3.3.8 的历史性能数字不应当作 4.0.2 的实测结果。
